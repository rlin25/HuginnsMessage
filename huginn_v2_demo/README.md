## Huginn v2 Demo

An interactive demo of [Huginn v2](https://github.com/rlin25/HuginnsMessage/tree/master/huginn_v2), a LangGraph-based AI agent that classifies financial trade exceptions and decides whether to auto-resolve them or escalate to a human reviewer.

**[Live demo →](https://rlin25.github.io/HuginnsMessage/)**

The `docs/` directory contains the design documents — masterplan, interface contract, UI spec, and design decisions — that governed the demo's implementation.
